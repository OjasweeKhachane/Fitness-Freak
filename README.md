# Fitness-Freak
Fitness Freak Website - with AI Coach 
Fitness Freak is an AI-powered Fitness Platform.
Its key features are :
  Custom plans tailored specifically to your goals
  Track workouts and improvements effortlessly
  Healthy meal suggestions and calorie management
  Get intelligent fitness recommendations instantly

It takes inputs like weight, height, goal, duration from the users.
This helps the AI Fitness Coach to generate a personalized workout planner.
